# Медси Бот: правила для облачных задач

Этот репозиторий является исходником для Timeweb, Cloudflare и Apps Script.
Он не содержит реальных данных пациентов, сообщений, отчётов, медиа, токенов
или паролей.

## Релизные границы

- `timeweb-next` — единственная ветка веб-релиза Timeweb.
- Не пушить напрямую в `timeweb-next`; изменения идут через отдельную ветку и PR.
- Не запускать Cloudflare или Apps Script workflow без явного запроса пользователя.
- D1-миграции только добавляются новыми файлами: не редактировать уже выпущенные
  миграции и не применять их без отдельного подтверждения.
- Не отправлять сообщения, отчёты или вложения в eXpress без прямого подтверждения
  пользователя в текущем чате.

## Перед любым PR

Выполни `npm run verify` из корня. Если изменялись Cloudflare или Apps Script,
укажи в отчёте, какой ручной релиз потребуется после merge.

## Источник истины

- Frontend и Timeweb gateway: корень репозитория.
- Основной Cloudflare чат-Worker: `services/cloudflare/chat-worker`.
- Cloudflare gateway: `services/cloudflare/chat-gateway`.
- Cloudflare push-worker: `services/cloudflare/push-worker`.
- Apps Script: `apps-script/medsi-bot`.

Не считай содержимое dashboard или локальных папок источником истины, пока оно
не сравнено с соответствующей опубликованной версией и не зафиксировано в Git.
