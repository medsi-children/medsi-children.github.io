# Медси Бот: правила для облачных задач

Этот репозиторий является единственным исходником сайта Timeweb, Apps Script
и Cloudflare Workers. Он не содержит реальных данных пациентов, сообщений,
отчётов, медиа, токенов или паролей.

## Релизные границы

- `timeweb-next` — единственная ветка веб-релиза Timeweb.
- Обычные изменения в `timeweb-next` публикуются автоматически после успешной
  проверки `npm run verify`: Timeweb, Apps Script или затронутый Worker.
- Для новых задач сначала сверить актуальный `timeweb-next`, workflow и живые
  настройки сервисов. Между запросами код мог измениться.
- D1-миграции только добавляются новыми файлами: не редактировать уже выпущенные
  миграции и не применять их без отдельного подтверждения.
- Не отправлять сообщения, отчёты или вложения в eXpress без прямого подтверждения
  пользователя в текущем чате.

## Перед публикацией

Выполни `npm run verify` из корня. Если изменялись Cloudflare или Apps Script,
проверь, что менялся только нужный компонент.

## Источник истины

- Frontend и Timeweb gateway: корень репозитория.
- Apps Script: `apps-script/medsi-bot/`.
- Cloudflare Workers: `services/cloudflare/`.
- `services/cloudflare/chat-worker/migrations/` остаётся только историей и
  ручным обслуживанием D1; её изменение не выпускает Worker автоматически.

Никогда не добавляй `.clasp.json`, реальные Script Properties, токены,
deployment ID или данные таблиц. Старые копии из архивов не считай актуальным
исходником.
