  Apps Script за 2497 мс. Это не проверка авторизованного списка.

## Что изменено

Один владелец сессии в tutor shell; все операции transport получают актуальную
сессию перед запросом. HTTP 401 запускает одно общее обновление и один повтор.
403 и сетевые ошибки не запускают перевыпуск ключей. Родительский transport без
поставщика tutor-сессии сохраняет прежнее поведение. Идентификаторы повторяемых
записей сохраняются. Prewarm больше не выпускает ключ самостоятельно.
Дублирование обновления на клиенте и сервере сокращено; список детей читает
только Cloudflare. Предзагрузка и открытие списка детей разделяют один запрос.
Навигация списка доступна при загрузке; при ошибке показывается повтор.

## Проверка и пределы вывода

`npm run verify` прошёл. Отдельно проверены текущий ключ вместо старого ключа
открытого экрана, HTTP 401 → обновление → повтор, предел одного обновления,
совпадение ID операции при повторе, один auth-запрос при одновременных вызовах.

Точная первоначальная причина отказа на устройстве воспитателя не доказана:
нет записи конкретного авторизованного запроса с этого устройства. Полученные
сетевые таймауты сами по себе не доказывают отказ сессии. Нельзя утверждать,
что секрет менялся, что ключи массово истекли или что виноват VPN. Пользователь
сообщил, что сбой есть без VPN. Проверку на физическом iPhone считать отдельной
непроверенной границей. Реальные сообщения и данные детей не выгружались.
