# Параметры воспитателя и просмотр родительской панели

Дата: 2026-10-22. Изменения подготовлены в `timeweb-next`; публикация отдельно
не подтверждена.

- В верхнем левом углу панели воспитателя добавлена малозаметная шестерёнка
  «Параметры».
- В меню есть выбор профиля ребёнка для просмотра родительской панели,
  включение/отключение уведомлений и удаление ребёнка через прежнюю очередь.
- Просмотр открывает настоящую родительскую страницу и получает подписанный
  временный токен на 15 минут. Токен остаётся в `sessionStorage`, не заменяет
  сессию воспитателя и не записывает сессию родителя в `localStorage`.
- Worker допускает для такого токена только GET-запросы профиля, отчётов,
  статуса непрочитанного и чата выбранного родителя. Запросы на отправку,
  изменение прочитанности и другие записи отклоняются. Родительский интерфейс
  в режиме просмотра не запускает push и не вызывает отметки «прочитано».
- Удалён интерфейс повторной авторизации воспитателем и связанные файлы
  `tutors/access-requests.js` и `tutors/access-requests.css`. Backend-переходы
  оставлены отдельно от этой очистки.

Проверки: `node --check` для изменённых JS-файлов, `git diff --check` и
`npm run verify` прошли.

Не проверено: визуальный просмотр на реальном телефоне и использование
предпросмотра в опубликованной среде. Worker и Apps Script в этом изменении
не выпускались.
