# Отделение действующей системы от прежнего Sheets-чата — 21.10.2026

## Проверенная карта ответственности

- Timeweb не только публикует HTML: gateway, защита/перевыпуск сессий,
  same-origin bridge к Apps Script и Worker, загрузка/выдача S3, preview.
- Cloudflare Chat Worker/D1: переписка, read-флаги, реакции/закрепления,
  профили, регистрация/повторная авторизация, очереди регистрации/отчётов/выписки.
- Push Worker/KV: действующие браузерные подписки и доставка уведомлений.
- Apps Script/Sheets: REPORTS и raw-отчёты, NAME_VARIANTS, принадлежность отчётов,
  admission-барьер, проекция регистрационного outbox в REPORTS, синхронизация
  REPORTS → D1, Google-контакты, история/уведомления, очередь удаления S3.
- Новые вложения: S3 Timeweb, в D1 — ссылки/ключи; поддержка старых Drive/KV
  ссылок остаётся. Старые файлы и история сообщений не удалялись.

Регистрация: браузер → Worker → D1 + outbox → зеркало/периодическая обработка
Apps Script → REPORTS/DATABASE + admission-epoch. Периодический путь является
повтором при сбое браузера, а не лишним дубликатом. Его сохраняем.
Выписка: закрытие D1, контроль ожидаемой личности, чистка raw-отчётов и REPORTS,
контактов и inactivity-state, очередь S3. Ни один из этих этапов не зависит от
Sheets-чата после этой правки. Ручное удаление REPORTS продолжает lifecycle-sync.

## Что удалено из исполняемого кода

53 реализации прежнего чата/индексов/вложений/очистки перенесены без изменения
в архив с контрольными суммами. 23 HTTP-имени оставлены как явный ответ о снятом
клиенте. Старый HTML-adapter больше не загружается в Apps Script.
Справочник телефонов, выписка и reconcile больше не сканируют и не пересобирают
CHAT_MESSAGES/CHAT_INDEX/CHAT_PINS. Чтение профиля не подставляет устаревшее имя
из старой переписки при ошибке D1.

Старые `cleanupInactiveChatMessages`/`cleanupExpiredChatImages` — безопасные
совместимые обработчики без обращения к Sheets/Drive. Их таймеры снимаются при
следующем обычном `ensureReportsD1ProfileSyncTriggers_`. Современные обработчики
синхронизации, очередей и отчётов сохраняются.

Из HTTP-whitelist убраны внутренний writer регистрации, распределение,
maintenance/cache и ручные диагностические команды. Writer регистрации получил
private-имя с `_`; два внутренних вызова сохранены. У публичных D1-fallback
родителя проверяется подписанная сессия до доступа к истории/отправке; совместимый
sender передаёт её дальше. Whitelist имеет null-prototype и own-property проверку.
Современные роли/доступ к D1 не заменены авторизацией по номеру телефона.

## Доказательства и ограничения

Все 5 актуальных HTML-входов (`index`, `tutors`, `psychology`, два test-входа)
и рекурсивные локальные script-ссылки проверены: 56 файлов, 11 literal API-имён;
старый adapter не достижим. API bridge Timeweb сверялся отдельно.
Это карта текущего checkout, а не доказательство отсутствия вечного старого
клиента в открытой вкладке: ему возвращается явная ошибка обновления.

Сравнение AST с `991b30e`: 314 оставшихся функций не изменены, включая правила
имён/ownership/оба распределителя. Writer регистрации изменил только имя.
Изменения 16 существующих функций перечислены diff; они касаются границ доступа,
выключения старого storage, совместимости и ручного тестового номера.
Актуальный индекс — `2026-10-21-apps-script-functions-after-retirement.tsv`.
Прежний индекс сохранён как снимок до чистки.

Локально `npm run verify` прошёл: 171/171 тест, синтаксис 96 рабочих источников,
source-control и smart-bot. `git diff --cached --check` — без ошибок.

8 дополнительных тестов: целостность архива, отказ старых методов/внутреннего
HTTP/prototype-имён, безопасные триггеры, отказ неверной родительской сессии до
сети, передача валидной сессии, выписка без старых листов с сохранением D1/raw/
контактов, справочник и Cloudflare-first профиль, достижимые UI-вызовы.
Полный verify включает прежние сценарии новых родителей/повтора регистрации,
смены roster/госпитализации, двух родителей, тёзок и пола, собственности отчёта.
Боевые тестовые регистрации, выписки и отправки не выполняются.

## Таблица и следующий этап

Подтверждены три устаревших листа: CHAT_MESSAGES, CHAT_INDEX, CHAT_PINS.
Проверка только formulaValue по существующим границам всех 15 листов не нашла
формул; сообщения и сведения пациентов для анализа кода не выгружались.
Создана отдельная нативная копия всей таблицы, метаданные всех 15 листов сверены.
Удаление трёх листов выполняется после проверки опубликованного Apps Script;
результат фиксируется в локальном DOCUMENTATION/VERIFIED_STATE.md.

PARENT_ACCESS_REQUESTS нужен для однократного импорта прежних заявок; он остаётся,
поскольку значение migration-флага нельзя подтвердить безопасным read-only способом.
Проверка 21.10.2026 установила, что одноимённый Google Sheet
PARENT_REGISTRATION_ATTEMPTS не имеет потребителей в текущем коде: действующая
регистрация использует одноимённую таблицу Cloudflare D1, которая остаётся нужна.
Google-листы PUSH_SUBSCRIPTIONS и PARENT_REGISTRATION_ATTEMPTS удалены из рабочей
таблицы после проверки отдельной полной резервной копии. Пять старых Apps Script
девять старых Apps Script-функций Google-хранилища/клиентского push-пути сохранены в
`archive/apps-script-legacy-push-subscriptions/`;
активные подписки проходят через Push Worker и его KV. `PARENT_ACCESS_REQUESTS`
и D1 `parent_registration_attempts` не удалялись. Основное ядро имён/ownership,
порядок lock и формат identity не переписывались; риски описаны в
`apps-script-structure.md`.
