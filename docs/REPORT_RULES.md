# Правила утренних и вечерних отчётов

## Общие проверки

Единый исходник: `tutors/report-validation.js`. Apps Script использует
идентичную копию `apps-script/medsi-bot/report-rules.js`.
После изменения исходника: `npm run sync:report-rules`.
`npm run verify` блокирует публикацию при расхождении файлов.

Критические ошибки: пустой отчёт, отсутствие оформленных детских блоков,
заголовки «Для врачей» / «Общий комментарий», повторяющиеся или неоднозначные
имена в оформленных блоках. Популярные формы имён проверяются на неоднозначность,
но не переименовываются. Единственное имя без инициала допустимо.

Разные тире, пробелы, номер палаты перед именем, отсутствие точки у инициала,
вступление и автор отчёта не являются ошибками. Упоминание имени без разделителя
не создаёт детского блока. Психотерапия не использует эти правила детских блоков.

## Этапы

1. Сайт выполняет общие проверки исходного текста, затем сохраняет отчёт
   на сервере и показывает «Готово». Ожидания распределения нет.
2. Apps Script выполняет те же общие проверки исходного текста. Этот этап
   используется и при ручной вставке в ячейку. Ошибка оставляет исходный текст
   в ячейке и добавляет примечание, распределение не запускается.
3. Apps Script корректирует заголовки и сопоставляет детей с REPORTS и
   NAME_VARIANTS. Только этот этап зависит от актуальной таблицы. Неоднозначные
   назначения не угадываются; сохраняется прежнее поведение пропуска таких блоков.

## Номера палат 501–512

Удаляются номера перед оформленным заголовком ребёнка, а также отдельные
строки с номером перед следующим оформленным заголовком (пустые строки допустимы).
До первого детского блока номера могут удаляться из вступления.
После начала детского блока числа внутри его текста сохраняются, включая
упоминания палат, двоеточия после чисел и отдельные числовые строки, которые
не находятся перед следующим детским заголовком.

Правила не определяют медицинский смысл текста. Отсутствие служебного
заголовка не является гарантией, что его содержание не попадёт в описание ребёнка.
