# Медси Бот — финальный план миграции в production

Дата фиксации: 6 сентября 2026

## Целевая архитектура

- Google Sheets + Apps Script — источник истины по детям, родителям, доступам и отчётам.
- Timeweb Node.js — production frontend/backend gateway и слой сессий.
- Cloudflare D1 — сообщения, реакции, прочитано/непрочитано, закрепления.
- Timeweb S3 — фото и видео чата.
- Cloudflare Push Worker — push-уведомления.
- GitHub — исходный код и autodeploy Timeweb.

## Правило миграции

До переключения домена ничего старого не удаляем. Старый Apps Script production остаётся рабочим аварийным вариантом до завершения smoke-test и нескольких дней стабильной работы новой схемы.

## Этап 4 — Google Sheets становится постоянным master-источником

После того как D1 и S3 приведены к актуальному состоянию:

- [ ] Добавить installable `onEdit` для листа `reports`.
- [ ] Добавить installable `onChange` для добавления/удаления строк и структурных изменений.
- [ ] Изменение телефона должно мигрировать D1-чат со старого номера на новый, включая ссылки на S3-вложения.
- [ ] Удаление ребёнка должно удалить его чат из D1 и вложения из S3.
- [ ] Изменение имени/прочих метаданных должно синхронизироваться без изменения истории сообщений.
- [ ] Ошибки синхронизации должны логироваться и не ломать редактирование таблицы.
- [ ] Эти триггеры не должны участвовать в пользовательских запросах бота и не должны влиять на скорость родительской/воспитательской панели.
- [ ] Добавить ручную функцию полного reconcile `reports -> D1/S3` на случай пропущенного события триггера.
