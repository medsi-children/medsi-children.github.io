# Облачный контур Медси Бота

## Назначение компонентов

| Компонент | Где работает | За что отвечает |
| --- | --- | --- |
| Веб-интерфейс и gateway | Timeweb | Панели родителей, воспитателей и психологов; статические файлы, проксирование и S3-медиа |
| `medsi-chat-worker` | Cloudflare Worker + D1 + KV | Чаты, вложения, сессии D1, снапшоты и фоновые задачи |
| `medsi-chat-gateway` | Cloudflare Worker | Узкий service-binding прокси к основному чат-Worker |
| `medsi-push-worker` | Cloudflare Worker + KV | Web Push-подписки и уведомления |
| Apps Script и Google Sheets | Google | Распределение отчётов, таблица, авторизация и фоновая синхронизация с Cloudflare |

## Исходный код

Код каждого компонента находится в этом репозитории. Данные в Google Sheets,
D1, KV, S3 и секреты остаются в соответствующих сервисах и в Git не попадают.

Перед первым выпуском из Git нужно сверить исходник с опубликованными версиями:

1. Apps Script обновляется через `clasp pull` и архивируется до импорта.
2. Для Worker проверяется опубликованная версия и список bindings через Wrangler.
3. Только после сверки подтверждённая версия попадает в PR. Если Cloudflare
   не позволяет выгрузить исходник через CLI, это отдельно фиксируется в PR:
   до ручной сверки dashboard такой импорт нельзя считать побайтной копией
   опубликованного Worker.

## Релизный поток

1. Агент создаёт ветку и PR.
2. GitHub Actions выполняет `npm run verify`.
3. После merge в `timeweb-next` Timeweb выпускает веб-интерфейс по существующей настройке.
4. Cloudflare и Apps Script выпускаются только вручную через отдельные workflow
   с защищёнными GitHub Environments.

Это разделение не даёт случайной правке Worker или Apps Script попасть в
продакшен вместе с обычной правкой интерфейса.
