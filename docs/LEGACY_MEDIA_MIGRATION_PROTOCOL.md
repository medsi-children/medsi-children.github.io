# Безопасный перенос старых вложений чата

Этот протокол применяется только после точной сверки `CHAT_MESSAGES` и D1. Он
не удаляет Drive- или KV-источник и не включает D1 как рабочий backend.

## Защищённый приёмник Timeweb

Timeweb получает `POST /__migration/media` только от server-to-server процесса
с заголовком `X-Medsi-Migration-Secret`. Значение сравнивается с
`MIGRATION_SHARED_SECRET` в окружении Timeweb и никогда не передаётся в
браузер. Пока переменная не задана, маршрут отвечает как отсутствующий.

Запрос обязан содержать:

- бинарное тело исходного файла;
- исходный MIME-тип и имя файла;
- `Content-Length` от 1 байта до лимита чата;
- `X-Medsi-Source-Sha256` — SHA-256 исходного файла в нижнем hex-формате.

Приёмник кладёт файл в S3, читает его обратно из S3 и сравнивает SHA-256. При
расхождении или любой ошибке созданный объект удаляется. Успешный ответ
содержит только `s3:<key>` и проверенный SHA-256.

## Порядок одного вложения

1. Зафиксировать в журнале `message_key`, исходный `file_id`, размер и SHA-256.
2. Прочитать исходник из Drive или Cloudflare KV без удаления.
3. Отправить байты в защищённый Timeweb-приёмник.
4. Принять результат только если его SHA-256 равен исходному.
5. Повторно получить объект через штатный `/media/s3/:key`; сверить HTTP 200,
   размер, MIME-тип и SHA-256.
6. Только теперь idempotent upsert этого же `message_key` в D1 меняет
   `file_id` на `s3:<key>`. Все остальные поля сообщения сохраняются без
   изменений.
7. Записать результат в журнал миграции. Drive/KV не удалять.

Повторный запуск сначала читает D1. Если `file_id` уже `s3:` и проверка объекта
успешна, он пропускает сообщение. Если `s3:` ссылается на отсутствующий или
повреждённый объект, процесс останавливается для ручной проверки, не подменяя
ссылку автоматически.

## Контрольные точки

- До записи: полный audit ключей Sheets ↔ D1, без дубликатов логической
  идентичности `phone10 + createdAt + side`.
- После каждой порции: количество источников, успешных S3-копий, обновлённых
  D1-ссылок, пропусков и ошибок должно сходиться.
- Перед cutover: все D1-медиа имеют `s3:` и выборочные фото/видео открываются
  в родительской и воспитательской панели через Timeweb origin.
