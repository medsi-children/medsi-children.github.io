# Инвентаризация репозитория — 2026-09-07

Этот список фиксирует состояние после переноса на Timeweb. Он нужен для понятной последующей уборки без удаления аварийных путей.

## Рабочий production-код

- Корень: `index.html`, `tutors.html`, `psychology.html`, `server.js`, PWA-ассеты и `notify-client.js`.
- Родительская панель: `parents/`.
- Панель воспитателей: `tutors-app/`.
- Общие чат-модули: `chat-overlay/`.
- Психологическая панель: `psychology-app/`.
- Server runtime: `lib/`.

Timeweb явно раздаёт только эти production-ресурсы. `backups/`, тестовые папки, документация, диагностические файлы и серверный исходный код не доступны по публичному URL.

## Legacy rollback — сохранить

- `appscript_test/` — аварийные Apps Script-инструменты: rollback чата, регистрация, удаление ребёнка и проверка отчёта. Не удалять без отдельной проверки Apps Script recovery-сценариев.
- `backups/web-ui-2026-09-04/` — исторический снимок интерфейса перед переходом на новую веб-оболочку.
- Git checkpoint branches — основной механизм отката рабочего UI. До отдельного аудита не удалять.

## Исторические тестовые копии — кандидат на архив

- `parents_test/` — предыдущий кандидат родительского веб-интерфейса.
- `tutors_test/` — предыдущий кандидат панели воспитателя.
- `psychology_test/` — тестовая версия психологии.
- `upload_test/` — ручная страница проверки загрузки.
- `parents/index.html` и `tutors-app/index.html` — старые входные HTML-копии, использующие соответствующие `*_test` файлы.

Они не участвуют в production и не раздаются Timeweb. Перед перемещением нужно лишь обновить внутренние ссылки между этими историческими файлами.

## Dev / operations — оставить закрытыми

- `diag.html` — диагностическая страница.
- `database/schema.sql` — историческая схема; PostgreSQL в production не используется.
- `ops/production-cutover-plan.md` и `docs/` — операционная документация.

## Предлагаемая следующая уборка — без удаления

1. Переименовать `backups/web-ui-2026-09-04/` в `archive/github-ui-before-timeweb-2026-09-04/`.
2. Перенести `parents_test/`, `tutors_test/`, `psychology_test/`, `upload_test/` и старые входные HTML-копии в `archive/ui-prototypes-before-production-2026-09/`.
3. Перенести `appscript_test/` в `archive/appscript-recovery-tools/`, сохранив содержимое и добавив README с предупреждением о ручном запуске.
4. После подтверждения новой структуры проверить, что production URLs и allowlist Timeweb не изменились.
5. Только потом составить отдельный план для локальных неотслеживаемых файлов. Папку `.wrangler/` пока не трогать: она не закоммичена.

Ни один пункт выше не подразумевает удаления исторического кода, Apps Script recovery-инструментов или данных чата.
