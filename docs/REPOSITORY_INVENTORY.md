# Инвентаризация репозитория — 2026-09-07

Этот список фиксирует состояние после переноса на Timeweb. Он нужен для понятной последующей уборки без удаления аварийных путей.

## Рабочий production-код

- Корень: `index.html`, `tutors.html`, `psychology.html`, `server.js`, PWA-ассеты и `notify-client.js`.
- Родительская панель: `parents/`.
- Панель воспитателей: `tutors-app/`.
- Общие чат-модули: `chat-overlay/`.
- Психологическая панель: `psychology-app/`.
- Server runtime: `lib/`.

Timeweb явно раздаёт только эти production-ресурсы. `archive/`, документация, диагностические файлы и серверный исходный код не доступны по публичному URL.

## Legacy rollback — сохранить

- `archive/appscript-recovery-tools/` — аварийные Apps Script-инструменты: rollback чата, регистрация, удаление ребёнка и проверка отчёта. Не удалять без отдельной проверки Apps Script recovery-сценариев.
- `archive/github-ui-before-timeweb-2026-09-04/` — исторический снимок интерфейса перед переходом на новую веб-оболочку.
- Git checkpoint branches — основной механизм отката рабочего UI. До отдельного аудита не удалять.

## Исторические тестовые копии — кандидат на архив

- `archive/ui-prototypes-before-production-2026-09/parents/` — предыдущий кандидат родительского веб-интерфейса.
- `archive/ui-prototypes-before-production-2026-09/tutors/` — предыдущий кандидат панели воспитателя.
- `archive/ui-prototypes-before-production-2026-09/psychology/` — тестовая версия психологии.
- `archive/ui-prototypes-before-production-2026-09/upload-check/` — ручная страница проверки загрузки.

Они не участвуют в production и не раздаются Timeweb. Перед перемещением нужно лишь обновить внутренние ссылки между этими историческими файлами.

## Dev / operations — оставить закрытыми

- `diag.html` — диагностическая страница.
- `database/schema.sql` — историческая схема; PostgreSQL в production не используется.
- `ops/production-cutover-plan.md` и `docs/` — операционная документация.

## Предлагаемая следующая уборка — без удаления

1. После подтверждения новой структуры проверить, что production URLs и allowlist Timeweb не изменились.
2. Только потом составить отдельный план для локальных неотслеживаемых файлов. Папку `.wrangler/` пока не трогать: она не закоммичена.

Ни один пункт выше не подразумевает удаления исторического кода, Apps Script recovery-инструментов или данных чата.
