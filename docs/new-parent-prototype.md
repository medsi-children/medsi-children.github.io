# Лаборатория Медси Бота

- Экспериментальный интерфейс открыт по адресу `/new`. Он не меняет основное меню родителей.
- Быстрые ответы и распознавание вопросов находятся в `parents/smart-bot.js`, интерфейс и реакции персонажа — в `new/`.
- На основном домене бот читает последние доступные отчёты через действующую защищённую родительскую сессию и `/lab/report-current`. На GitHub Pages защищённые отчёты недоступны.
- Отчёт по групповой психотерапии форматируется тем же модулем, что и на основной странице: `parents/psychology-format.js`.
- Родительская переписка с ботом видна только в открытой странице и сбрасывается при обновлении; она не сохраняется в `localStorage` и не становится историей чата для родителя. История отчётов остаётся в классическом меню, сообщения воспитателям — в их чате.
- На основном адресе отдельный диагностический журнал сохраняет полные тексты сообщений бота и родителей на 30 дней в Cloudflare KV. Это не история чата для родителей: после перезагрузки интерфейс остаётся пустым. Журнал не сохраняет имя или телефон, группирует сообщения по случайному идентификатору вкладки и доступен только по отдельному секретному ключу на `/new/logs.html`. Из `/new?logs=1` есть ссылка на журнал. На GitHub Pages и без родительской авторизации запись не ведётся.
- Новые записи в Cloudflare KV могут быть видны в журнале с задержкой. Для работы чтения нужен секрет Worker `BOT_LOG_VIEWER_TOKEN`; он не хранится в репозитории и не используется для остальных административных операций.
- Если бот не уверен в смысле вопроса, он уточняет тему. Неизвестный вопрос предлагает задать воспитателям. Бот не отправляет сообщения воспитателям самостоятельно.
- Адрес `/lab` занят защищёнными запросами к базе; для экспериментальной страницы сохраняется `/new`.

До переноса помощника в основное меню нужно отдельно проверить весь путь под родительской авторизацией на основном домене.
