# Local Twemoji subset

This folder contains the small Twemoji SVG subset used by Medsi Bot for chat reactions and menu-card icons.

Graphics source: Twitter Twemoji — https://github.com/twitter/twemoji
License: Creative Commons Attribution 4.0 International (CC BY 4.0) — https://creativecommons.org/licenses/by/4.0/

The SVG artwork is vendored locally so the UI does not depend on runtime requests to raw.githubusercontent.com. Unicode emoji values remain the stored chat data; these files are visual replacements only.
