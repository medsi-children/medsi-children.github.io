# Архив старых Apps Script интерфейсов

`children.html`, `educators.html` и `psychology.html` — сохранённые копии
прежних родительской, воспитательской и психологической панелей Apps Script.
Они оставлены только для истории и восстановления;
в проект Apps Script не отправляются и не используются интерфейсом Timeweb.

В Apps Script оставлены серверные функции, которые нужны действующему сайту.
Актуальные панели всех трёх ролей находятся в корне сайта GitHub и продолжают
использовать Apps Script как сервер API там, где это необходимо.
