# Архив старых Apps Script интерфейсов

`children.html` и `educators.html` — сохранённые копии прежних родительской и
воспитательской панелей. Они оставлены только для истории и восстановления;
в проект Apps Script не отправляются и не используются интерфейсом Timeweb.

В Apps Script оставлены серверные функции, которые нужны действующему сайту.
Отдельная страница `psychology.html` не удалялась: её вывод из эксплуатации
требует отдельной проверки сценариев.
