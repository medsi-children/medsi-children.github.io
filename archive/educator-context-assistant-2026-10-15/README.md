# Архив контекстного помощника воспитателей

Снято из active production-кода `timeweb-next` на commit `482f290f6ced713f315b7ad0332966163b2b4bac` 2026-10-15.

Это именно автоматический помощник внутри чата воспитателей, который анализировал новые сообщения родителей и показывал блоб «Кажется, здесь могу помочь. Предложить ответ?».

По решению пользователя эта функция удалена из активной воспитательской панели, потому что на практике отвлекала от работы. Архив оставлен только как reference и **не должен подключаться к production**.

Файлы:
- `context-assistant.js` — логика классификации и runtime карточки.
- `context-assistant.css` — стили карточки.

Ручные быстрые ответы воспитателей и отдельный `tutors/assistant.js` этим архивом не заменяются и не относятся к отключённому автопомощнику.
