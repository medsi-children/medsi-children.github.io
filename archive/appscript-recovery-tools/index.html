Apps Script test bench

Отдельная диагностическая страница. Боевые листы отчётов не трогаются. Этап 2 пишет только в отдельный лист TEST_REPORTS_API.

Этап 1 — проверка связи

Вызов безопасного существующего метода checkPhoneExists. Если тест проходит, значит fetch, doPost, API-dispatch и чтение таблицы работают из GitHub.
Ожидание теста.

Этап 2 — тест записи отчёта

Проверяет реальную цепочку GitHub → Apps Script → авторизация воспитателя → запись → чтение записанной строки обратно. Используется только тестовый лист.
Ожидание теста записи.
