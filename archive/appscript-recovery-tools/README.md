# Apps Script recovery-инструменты

Здесь находятся ручные страницы для аудита rollback чата, тестовой регистрации, удаления ребёнка и проверки отчёта.

Они не доступны через публичный Timeweb-сайт и не являются обычной частью приложения. Перед запуском любого инструмента сначала проверить его сценарий и актуальность Apps Script API: некоторые страницы относятся к историческому `tutors_test` окружению.
