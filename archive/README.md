# Архив интерфейсов и recovery-инструментов

Эта папка не раздаётся Timeweb и не участвует в production.

- `github-ui-before-timeweb-2026-09-04/` — снимок GitHub-интерфейса до Timeweb migration.
- `ui-prototypes-before-production-2026-09/` — прежние web-кандидаты для родителей, воспитателей, психологии и загрузки файлов.
- `appscript-recovery-tools/` — ручные Apps Script-инструменты восстановления и проверки.

Содержимое архива сохраняется как исторический и аварийный материал. Не использовать его как обычный production-код и не удалять без отдельной retention-политики.
