# Прежний чат в Google Sheets — снят 21.10.2026

`retired-chat.js` сохраняет 53 исторические реализации из baseline `991b30e`.
`manifest.json` содержит исходные файлы/строки и SHA-256 каждого тела функции.
Это фрагменты прежнего общего проекта, не самостоятельная программа: для восстановления
нужен review исходника и зависимостей. Каталог не попадает в clasp и исключён из
проверки синтаксиса рабочих исходников; отдельный тест проверяет все 53 контрольные суммы.

Текущие панели общаются с D1 через Worker/Timeweb. Прежние 23 HTTP-метода явно
возвращают `LEGACY_CHAT_RETIRED`, не читают/пишут Sheets и не удаляют медиа.
Два старых обработчика таймеров сохранены в рабочем Apps Script как безвредные
ответы: уже поставленный таймер не может восстановить старые листы. Регулярная
установка профильных триггеров удаляет только эти два устаревших таймера.

Старый HTML-adapter сохранён отдельно в `archive/apps-script-legacy-ui/` и исключён
из загрузки в Google. История `991b30e` сохраняет полный контекст реализации.
Служебные листы чата удаляются только после выпуска кода и отдельной резервной
копии таблицы. Данные D1, KV, S3 и Drive этой чисткой не удаляются.
